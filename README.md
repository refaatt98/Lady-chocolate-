# الليدي شوكولات — Lady Chocolate

واجهة موقع متجر شوكولا بلجيكية. الطلب بيصير عن طريق واتساب.

## التشغيل

```bash
npm install
npm run dev
```

بعدها افتح الرابط اللي بيطلع بالترمينال (عادةً http://localhost:5173).

| الأمر | شو بيعمل |
| --- | --- |
| `npm run dev` | تشغيل للتطوير |
| `npm run build` | فحص الأنواع وبناء نسخة الإنتاج بـ `dist/` |
| `npm run preview` | تجربة نسخة الإنتاج محليًا |
| `npm run lint` | فحص الكود |

## الستاك

React + TypeScript · Vite · Tailwind CSS v4 · React Router · motion · lucide-react

## هيكل المشروع

```
src/
  pages/        صفحة لكل ملف
  components/   مكوّنات مشتركة
  data/         بيانات وهمية (منتجات، أقسام، معلومات المحل)
  lib/api.ts    كل جلب البيانات بيمر من هون
  types.ts      أنواع البيانات
  index.css     الألوان والخطوط (tokens)
public/images/  صور المنتجات
```

## تعديلات سريعة

- **الألوان والخطوط:** بـ `src/index.css` داخل `@theme`.
- **رقم الواتساب والعنوان:** بـ `src/data/site.ts`.
- **المنتجات:** بـ `src/data/products.ts`، والصور بـ `public/images/products/`.
- **الأقسام:** بـ `src/data/categories.ts`.

## الطلب

ما في دفع بالموقع. الطريق كامل:

1. **صفحة المنتج:** الحجم، والتخصيص (اسم/تاريخ مع معاينة على الصينية)، وملاحظات على الصينية، وبعدين "ضيف للطلبية".
2. **طلبيتي (`/cart`):** المنتجات (بتقدر تعدّل الكمية والملاحظة)، ومعلومات التوصيل (الاسم، الرقم، توصيل أو استلام،
   المدينة، العنوان، رقم المستلم، الموعد والوقت)، وملاحظات الطلب، وخيار هدية مع كرت.
3. **الإرسال:** بيتولّد رقم طلب، وبتنفتح رسالة واتساب مرتبة فيها كل إشي.

السلة ومعلومات الزبون بيتحفظوا بالمتصفح (localStorage).
الإعدادات (رقم الواتساب، المدن المقترحة، ملاحظة التوصيل، أقل عدد أيام للتحضير) بـ `src/data/site.ts`.

## الرفع على Netlify

كل الإعدادات بـ `netlify.toml`: أمر البناء، ونسخة Node، وتحويلات React Router، والكاش، وهيدرز الأمان.
ومعها `public/_redirects` احتياطًا للرفع اليدوي.

1. ادخل على Netlify واختار **Add new site ← Import an existing project ← GitHub**.
2. اختار الريبو، والفرع اللي بدك تنشره.
3. اكبس **Deploy**. ما في داعي تعبّي أي إشي، الإعدادات بتنقرأ من الملف.

بعدها كل `git push` على نفس الفرع بيعمل نشر جديد لحاله.

## ربط Supabase لاحقًا

الصفحات ما بتقرأ من `src/data/` مباشرة. كلها بتستدعي دوال `src/lib/api.ts`.
لما نربط Supabase، بنغيّر جسم هالدوال بس، ومنخلي أسماءها وأنواع اللي بترجعه زي ما هي.
